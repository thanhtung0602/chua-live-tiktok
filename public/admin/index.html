Dùng trình giả lập ở tab Tổng quan để thử toàn bộ luồng trước khi tích hợp thật.

WEBHOOK API

Endpoint nhận sự kiện

POST /api/live/events

Gửi header x-live-secret (hoặc Bearer token) bằng giá trị LIVE_WEBHOOK_SECRET. Sự kiện hỗ trợ: like, gift, comment.

Mẫu payload quà 
{
  "type": "gift", "eventId": "provider-id-1",
  "viewer": { "id": "u-1", "username": "thanh_tung", "nickname": "Thanh Tùng" },
  "giftId": "lion", "repeatCount": 1
}
